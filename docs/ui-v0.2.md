# Moonlight 0.2.0 UI

Independent Compose implementation inspired by the organization observed in the supplied Librus 8.0.4 package: drawer navigation, dashboard sections, day/week/month schedule modes, grade list and message screen. No original APK resources, source code, logos or account code are included.

The header permanently identifies Moonlight as an unofficial planner; data provenance is visible. The local importer and background refresh remain available. Grades and lesson statuses are read-only imported entries, not verified school records. The former demo cancellation editor is not present in the journal screens. The personal calculator and private lists are separate. Modules without a connected source show an explicit unavailable state. No direct Librus authentication or server synchronization is implemented.

Day/week/month are list filters, not a graphical calendar grid. Import schema v1 lacks grade period information, messages and attendance, so the app does not fabricate them.
